# 💫 About Me:
Hi, I'm Victor — a software engineer currently transitioning from frontend and data science into Cloud and Platform Engineering.

I have a strong background in building web applications using Next.js, TypeScript, and modern frontend tooling, along with experience in data analytics and visualization using R and Power BI.

Furthermore, I have a working understanding of core supervised and reinforcement learning algorithms, including decision trees, random forests, regression models, and Q-learning. This has given me insight into how data-driven systems learn, make decisions, and scale.

Right now, my focus is toward cloud infrastructure, backend systems, and DevOps engineering. I am a building hands-on cloud projects to strengthen my understanding of real-world infrastructure systems.

I’m especially interested in how scalable systems are designed, deployed, and maintained in production environments. Also, I’m working toward opportunities in cloud and platform engineering.

Tech is the future — and I aim to build the infrastructure for those building the future!.
